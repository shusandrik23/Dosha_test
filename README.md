# Dosha test — тест на определение доши (Android)

Нативное Android-приложение (Kotlin + Jetpack Compose).

## Что умеет

- Перед тестом спрашивает **имя и возраст** и предлагает выбрать **20, 35 или 50 вопросов**.
- **Шкала «насколько похоже»**: в каждом вопросе три коротких утверждения (Вата, Питта, Капха) в случайном порядке; для каждого выбирается «Не про меня» (0), «Немного» (1) или «Очень похоже» (2) балла этой доше.
- **Переключатель «Вопрос / Ситуация»** над 22 взрослыми и 10 детскими общими вопросами (характер, поведение, энергия, кожа): вместо общего вопроса можно ответить на жизненную ситуацию с такой же шкалой (`data/Situations.kt`).
- **До 12 лет включительно — детская версия**: свои 50 вопросов на «ты», про игры, еду, сон, садик и школу; результат и советы тоже для ребёнка.
- **Язык — по языку телефона**: русский, если система на русском; английский для всех остальных.
- **Результат**: проценты каждой доши, тип (одна доша; двойной тип, если разница первой и второй ≤ 10%; сбалансированный, если все три в пределах 8%), описание, сильные стороны, признаки дисбаланса, рекомендации (питание, режим, движение, уход, эмоции), совет по сезонам для смешанных типов.
- Кнопка **«Поделиться результатом»** — текст с типом, процентами и главными советами.
- **Сохранение результатов на устройстве**: кнопка «Сохранить результат» на экране результата; на первом экране — «Мои результаты» со всеми сохранёнными тестами (имя, возраст, дата и время, тип и проценты). Запись можно открыть заново или удалить. Хранение — `HistoryStore.kt` (SharedPreferences, JSON), в интернет ничего не отправляется.
- **Тест «Мой баланс сейчас» (Викрити)** — 20 вопросов о самочувствии за последние 2–4 недели (у детей 2–3 недели), отдельные для взрослых и детей. Варианты: «Норма» (0 баллов) и Вата / Питта / Капха (по 2 балла). Если «Нормы» не меньше, чем ответов любой доши, — доши в балансе; иначе ведущая доша вышла из равновесия; если вторая отстаёт не больше чем на 1 ответ — двойной дисбаланс. Вопросы — `data/VikritiQuestions.kt`, тексты результата — `data/VikritiTexts.kt`.

## Подсчёт

Каждое утверждение оценивается 0 / 1 / 2 балла своей доше. Проценты = баллы доши / все баллы × 100 (с округлением до суммы 100). Смешанные варианты (В+П, П+К, В+К) в файлах вопросов сохранены, но в шкале не показываются.

Короткий тест (20) — ключевые вопросы (`ADULT_CORE_20` / `KID_CORE_20` в `Model.kt`), 35 — первые 35 вопросов списка, 50 — все.

## Где что лежит (`app/src/main/java/com/moyadosha/app/`)

- `data/AdultQuestions.kt`, `data/AdultQuestionsEn.kt` — вопросы для взрослых (RU / EN, одинаковый порядок и баллы)
- `data/KidQuestions.kt`, `data/KidQuestionsEn.kt` — вопросы для детей
- `data/RecommendationsRu.kt`, `data/RecommendationsEn.kt` — описания типов и рекомендации
- `data/Strings.kt` — надписи интерфейса
- `data/Model.kt` — язык, наборы 20/35/50; `data/Scoring.kt` — подсчёт
- `ui/Screens.kt` — экраны

## Сборка

APK собирается в GitHub Actions при каждом push: **Actions → Android APK → Artifacts → dosha-test-debug**.
Локально: открыть папку в Android Studio или `./gradlew assembleDebug`.
